# 横屏按宽阅读：实施与验证

用户已确认横屏效果图，本次取代上一版横屏“整页缩进视口”的方案。手机竖屏及 iPad 竖屏保持此前布局。

## 实现

- 手机、iPad 横屏：教材按阅读区宽度等比显示，在固定视口内上下滚动；图片和音频热点共用完整图片尺寸、处于同一滚动内容层。
- 原有横向 Swiper 和切页确认逻辑保留。成功切页才切换对应原生滚动节点的 key；录音状态更新、取消切页均不切换当前 key。
- 横屏操作栏固定宽度：手机 180px，小横屏 160px，iPad 220px。回听、完成、重录纵向排列；上一页/下一页并排。
- 横屏标题压为单行，页码缩短，去掉需要离开当前阅读界面的“放大查看”。Pad 竖屏保留该入口。
- 仅已保留图片的页创建书内 ScrollView，复用原有最多 24 页保留策略；不会给整本书所有页创建空滚动容器。

## 验证结果

- `npm run test:regression`：**171/171 通过**。
- `npx tsc --noEmit --skipLibCheck`：通过。
- `npm run build:weapp`：通过；普通教材和 Think 页面注册检查通过。构建仍有既有 Sass 废弃及体积提示。
- 横屏/竖屏专项 30 项覆盖两条路由、录音状态稳定、图与热点同滚且能播放、旋转和后台返回、成功/取消翻页、草稿保留及滚动节点数量。
- 独立定向复核 **10/10 通过**：录音时取消目录或手势切页、确认切页、迟到的旧图片/录音回调、后台恢复。未发现必须修复的新问题。
- Sass 编译及样式规则比对通过：所有非横屏规则与修改前快照逐条一致；手机竖屏仍按宽显示且使用原 View 操作区，不增加书内 ScrollView。
- 右侧单行已保存状态的静态高度预算为 244px，按钮均保留 44px 点击高度；这是 CSS 尺寸计算，不是真机实测。
