# 上线前修复与验证结果

日期：2026-09-16。第一批本地修复完成：专项及全量回归、类型检查、微信构建、160 场景布局与独立整体复审通过。尚未部署，不能据此直接放量上线。

本轮只做代码修复和本地测试。没有部署、提交、推送、修改云权限或启用自动清理；没有读取、删除、迁移真实学生录音。线上仍需部署修复后的 checkIn 与配套小程序，不能把本地结果当成线上漏洞已消除。

## 已修复的范围

1. 旧 create 无条件拒绝新增，鉴权优先；详情、提交、本人删除及主动分享核验前校验文件引用，跨 owner 冲突或查询失败不签名、不读取或删除文件。协议 owner 路径校验涵盖尚未 commit 的文件，签名期限在引用检查后重算。
2. 重开正在分享的同一录音时接续观察已有任务，完成/失败均解除等待，不重复 submit，也不轮询。
3. 云删除失败保留“待删除 / 重试”，过期、有同一本机副本也不隐藏；不能继续回听/分享。重复删除去重，旧刷新和离页回调不能恢复已删卡片。
4. 本机已有链接提供“链接打不开？检查分享”。明确失效后仅使旧分享代次失效，下次主动点击才重新上传；本地音频不动。网络、权限、畸形 SDK 回包、存储写入失败保留原状态，迟到旧代结果不能清掉新代。
5. 移除四条 TypeScript 未使用项诊断，没有调整严格度或重做页面布局；补充两个真实恢复状态的布局场景及删除按钮文字边界检查。

独立复审发现并补严了“下载成功形状”检查：数值 HTTP 200、有效字节、无矛盾错误码，之后才核对文件大小和 SHA1。它避免把不确定下载结果误判为损坏并授权重传。

## 保持不变的业务边界

- 本地完成、回听不上传；只有主动点击分享才上传，有效分享复用。
- 30 天从首次 commit 起算，重试不续期，防重记录保留。
- 100 MiB 管理预算、10 MiB 余量、90 MiB 保存预算、82 MiB 开始录音门槛保持不变。
- 不自动删除本机历史，不清缓存；分享不是永久备份或换机迁移。
- 主动核验会产生一次云端读取相关用量，不在页面打开/播放时后台核验。
