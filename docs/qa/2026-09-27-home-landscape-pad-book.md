# 手机横屏首页及 iPad 书页放大验证

## 本轮范围

- 手机横屏首页使用固定 px：品牌 20px，封面 84×120px，继续卡片最小高 144px，书名 16px，操作按钮 44px；标题保留自然换行。
- 首页仍为单列滚动，系列列表压缩间距；横屏底栏 56px，并同步预留底部及左右安全区。
- iPad 竖屏书页改为按阅读区宽度显示，超出高度的内容在书区内上下滚动，图片与音频热点在同一内容层中。
- iPad 横屏操作栏从 220px 改为 180px，教材可用宽度增加 40px。
- 手机竖屏、iPad 首页以及手机横屏阅读器的布局行为保持原样；未修改录音、上传或本地空间检查逻辑。

## 验证边界

测试验证了组件状态与样式规则，未替代微信原生渲染。本轮没有生成新布局截图，也没有进行开发者工具或真机触摸测试。

重新编译后需在微信环境确认：

1. 手机横屏首页标题、封面及继续按钮可见；列表可以滚动到末尾，底栏避开安全区。
2. iPad 竖屏书页铺宽，书内上下滑动可到达页底，示范音频按钮与内容一起移动且可点击。

4. 手机竖屏视觉及操作保持原状。
