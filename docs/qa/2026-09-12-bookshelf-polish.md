## 发现并解决的问题

原书库底部安全区声明含旧版 `constant()`，压缩后被合并进整条 padding。无旧语法支持的环境会拒绝整个简写，导致左右内边距也变成 0。独立加载旧编译 CSS 测量曾得到左右均为 `0px`。

现使用独立有效的数值基础留白，将底部安全区声明放在对应 `@supports` 中。最终打包 WXSS 经浏览器计算左右留白正确。Pad 分隔线另改为固定像素，与其封面及文字间距一致，避免 rpx 随整窗宽度扩大。

## 验收操作

1. 微信开发者工具直接点击“编译”，无需清除缓存或本机录音。
2. 检查首页和 CASA 书库留白、册别、封面及重复标签是否符合预期。
3. 进入教材翻到另一训练页，返回首页点击“继续跟读”，确认书名与页码一致。
4. 书库选择一个系列并搜索、滚动到中间，进入教材再点返回，确认筛选、搜索词和滚动位置保留。
