## 正式发布前剩余事项

1. 从本次最终代码构建并上传正确版本；如尚未执行，只补一次容量恢复后的分享上传与接收播放确认，不重做整套测试。
2. 微信后台隐私指引不能继续声明“未采集用户隐私”：实际使用录音，并处理用户标识及分享记录；按实际处理方式填写，核对授权。若服务不满 14 周岁的学生，还需落实监护人同意和专门处理规则。
3. 核对教材使用授权、服务类目及后台要求的备案/审核资料。
4. 配置并核对费用、余额和运行异常通知。按量计费已开启不代表已有费用硬上限，也不代表已建立自动监控。
5. 独立完成清理部署与隔离样本验收。正式删除前再次确认环境、候选范围及数量，再由负责人开启开关和定时器；不清空测试库，不触碰手机本地文件。
6. 保留兼容当前本地数据格式的回退版本，再提交审核和发布。旧主目录不能直接当作安全回滚版本。

## 数据安全边界

- 本地录音不是跨设备备份；清除微信数据、换机、设备损坏仍可能导致文件丢失，不能承诺任何情况下永久保存。
- 新版云分享有效期与物理删除不是一回事；当前不能对外宣称到第 30 天云文件自动删除。
- 过期清理只处理通过绑定与引用校验的新版云文件，不迁移或删除教材，也不自动清理无期限旧云录音。
- 上传源码到 GitHub 不备份云端数据库、完整教材库或学生录音，也不触发云函数部署和小程序发布。
