# 本地录音与 30 天分享验收、部署说明

## 范围和数据规则

本次只改变学生录音生命周期，不搬迁教材、不更换云开发环境、不切换套餐、不增加付费审核服务。

- 完成练习：先将录音文件持久保存至本机，写入完成标记；不调用云函数或上传文件。
- 我的录音：先读取本地录音，云端历史作为兼容补充。云网络错误不遮盖本地录音。
- 第一次分享：点击“分享”才启动准备、上传、确认；准备好以后再点击“发送给朋友”。
- 有效期内再次分享：复用同一份云副本和原截止时间，不重复上传、不自动延长有效期。
- 新分享默认由服务端首次确认时起算 30 天。到期后旧链接不能再请求播放；再次主动分享创建新编号和新云路径。
- 云端过期清理与本地文件独立。上传成功、云端失效、清理重试都不能删除本地录音。
- 自动清理删除云端音频文件；数据库保留失效记录及原路径，用于阻止旧请求复活、重试清理迟到上传。这不等于清空全部数据库历史，容量监控也要计算这些记录。
- 旧版已上传记录可能没有本地副本；没有新协议期限的旧云记录不纳入自动清理。
- 本地不是跨设备备份。清除微信/小程序数据、换机、设备损坏后，本地录音不能保证恢复。容量不足必须提示，不自动淘汰旧录音。
- 正常本机加载和播放不调用云端。只有本人在本机回听失败后明确点击“从分享恢复”，客户端才为这一条记录请求授权恢复源；恢复不重新上传、不续期，全过程保留旧文件，仅在新文件校验并成功写入索引后替换记录中的路径引用。
- 恢复保存阶段的重试状态只存在于当前小程序进程。若文件已保存但索引写入失败，当前会话可复用同一保存路径重试，不再次下载或移动；进程结束后可能留下无法追踪的孤立保存文件，因此不能承诺永久存储或跨进程自动续接。

## 上线顺序

1. 保留已验收版本及当前工作分支，先在测试环境或开发版验证。不要清除小程序缓存来“解决”问题，这会损坏本地数据验收条件。
2. 在控制台核对云环境，按 `cloudfunctions/README.md` **先部署**包含 `recoverySource` 的 `checkIn`；上线前必须验证旧记录能读取、本人只能取得精确记录的短期恢复源，且返回地址满足 `wx.downloadFile` 合法域名要求。日志和配置不得记录带签名参数的完整 URL。
3. 核对新分享存储前缀和私有读取权限。不能全桶改成公开可读来绕过错误，也不能未经核查全桶改私有而导致教材图片和示范音频不可用。
4. `checkIn` 验证通过后再部署诊断与“从分享恢复”客户端，然后完成以下真机验收。只构建客户端不能替代先部署云函数。
5. 本次旧录音恢复修复不需要部署或启用 `cleanupExpiredShares`，也不需要清理任何录音或测试数据。若未来要启用删除，必须重新盘点具体云环境、候选记录/文件数量、截止范围和本机边界，并取得新的明确确认。
6. 未来获得确认后，自动清理仍须先以只读预演模式运行，核对候选记录全部属于新版分享、截止时间正确、文件路径没有教材或旧录音；再核实定时入口来源限制、所需索引、可信存储前缀、重试和失败日志，由环境管理者显式启用删除。代码进入仓库不等于线上已启用。

具体清理配置和受信入口以 `cloudfunctions/README.md` 的最终实现说明为准，不把数据库 TTL 当作音频文件删除。

## 手机和 Pad 验收

至少使用一台手机和一台 Pad，分别检查竖屏、横屏、安全区和按钮触控。自动测试不能代替真实麦克风、系统授权、音频解码、微信分享以及云权限测试。

| 场景 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 本地完成 | 先打开教材，断网后录音、回听、完成练习 | 不提示上传失败；进入本地录音详情 |
| 重启恢复 | 普通退出小程序后重新进入“我的录音” | 原录音可回听，页数和教材内页正确 |
| 正常分享 | 联网，点击分享，等待准备完成，再发送给朋友 | 接收者只能打开这一条录音，能播放并看到当前/总时长 |
| 同代重发 | 立即再次分享同一条录音 | 仍是同一链接和截止时间，后台不新增文件 |
| 上传失败 | 分享准备期间断网，再恢复后重新点击 | 本地仍可回听，失败不变成练习未完成，可重试 |
| 离页停止 | 播放中返回首页或进入其他页面 | 立即停止音频，播放显示复位 |
| 分享取消 | 上传期间离开页面，回到录音列表 | 可取消阶段收口，录音保留；不能在仍进行的提交中删除文件 |
| 录音兼容 | 示范音频与录音并行、暂停/继续、系统中断、切后台 | 不串录音、不丢已保存文件，不把旧回调绑定到新教材页 |
| 存储不足 | 测试适配器模拟 saveFile/元数据写入失败 | 明确提示未安全保存，不能虚报完成，不静默删旧录音 |
| 重试保存 | 模拟一次保存失败，恢复后点击“重试保存”，再正常退出重进 | 原段录音恢复为可长期回听的本机记录，不新增重复录音、不上传；已保存的文件不再次移动 |
| 保存时离页 | 重试保存仍在等待时离开详情或练习，再进入“我的录音” | 不在隐藏页补启动上传；成功保存后从同一个本地编号恢复 |
| 历史兼容 | 打开升级前的一条云端记录 | 可读取，不被新版 30 天清理规则影响 |
| 旧录音诊断与恢复 | 不清缓存，打开一条真实失败旧录音并播放；回传脱敏诊断后，本人点击“从分享恢复” | 普通失败探针和本机播放零云请求；日志只含固定阶段、短编号、白名单错误码、大小/指纹一致性及可用平台版本，不含完整标识、路径、URL 或原始 error；恢复只处理精确记录 |
| 恢复后离线重启 | 恢复成功后关闭小程序，断网重新进入并回听 | 同一本地编号可离线播放；旧路径在新索引成功前始终保留，无自动清理 |

## 过期与清理验收

优先使用自动化的可控时钟测试验证 30 天边界，不修改真实学生记录的截止时间。

如需在云测试环境实测，仅对专门创建的测试录音操作：

1. 新建测试录音并分享，记录其云端编号和文件路径。
2. 在测试环境使该测试记录到期，确认本人和持有口令的其他测试用户均不能重新获取播放链接。
3. 在原设备对同一本地录音再次分享，确认新旧云编号、口令和路径均不同，本地只保留一条录音。
4. 再打开旧链接，必须仍失效，不能因为重新分享而恢复。
5. 清理预演只列候选、不删文件；启用测试删除后验证对象删除与状态收敛。
6. 模拟删除失败、文件已不存在和终态写失败，确认可以重试，不能提前丢弃文件引用。
7. 上传完成但未确认的文件也需要清理兜底；缺少可信文件前缀或存储事件能力时，不得宣称已覆盖全部孤儿文件。

分享截止与物理删除不是同一时刻：服务端到期先拒绝访问，后台批量删除允许有调度延迟。已经签发的临时 URL、CDN/播放器缓存、接收者主动下载或转存的音频，不能承诺远程即时撤回。
