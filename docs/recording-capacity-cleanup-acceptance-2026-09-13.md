# 录音安全余量与云端清理验收

本报告区分本地实现和线上部署；本地测试不是云端已启用的证据。

## 本地容量保护

已取消 500 条业务数量上限，改为读取微信 `saveFile` 管理区实际文件大小。统计包含未被录音索引引用的已保存文件，按路径去重，不读取音频正文、不自动删除文件。

| 保护层 | 已实现规则 |
| --- | --- |
| 总业务预算 | 100 MiB；其中固定保留 10 MiB，不分配给新录音 |
| 开始录音 | 再预留单条 8 MiB，已用空间不超过 82 MiB 才允许开麦 |
| 持久保存 | 新文件保存前“实际已用 + 本次大小”不超过 90 MiB；已移动文件重试只补索引，容量未知或超限不阻断恢复，不再复制文件 |
| 未知用量 | 统计失败或数据无效时拒绝新录音，不把未知当作空闲 |
| 保存后校准 | 再读实测用量；越限或统计失败仍保留本次已保存路径和索引，提示用户，不回滚删除录音 |
| 离页竞态 | 容量检查返回后复核页面、教材与录音会话，失效点击不会启动麦克风或清掉旧录音 |

这里的 MiB 为 1024 × 1024 字节。该预算不是手机剩余容量，也不是对微信实际可用空间的保证；目前统计范围是本小程序的 `saveFile` 管理区，不覆盖任意用户目录。当前项目的持久音频写入均经过此保存链。

已验证空间边界和多 1 字节、501 条短录音、未索引文件、统计失败、重试去重、保存后大小校准、离页竞态及真实磁盘文件恢复。尚未在真实手机/iPad 上执行接近容量上限的原生压力测试。空间检查与实际保存不是原子操作，设备空间突变或原生 IO 失败仍依赖现有回听与恢复机制保护。

## 数据边界

保留主动分享才上传、服务端首次确认起 30 天、有效期内复用与过期重新分享的新代次。云端到期和物理删除不影响本机文件，过期不能撤回他人已下载的音频。旧无期限云记录不进入新版自动清理。

预留安全余量无法保证设备永不发生空间骤减或 IO 错误；必须同时保留保存失败、回听和恢复保护，不能向用户承诺绝对不丢失。
