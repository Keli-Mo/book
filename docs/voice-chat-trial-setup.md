# 英语语音伙伴试用配置

本试用版使用腾讯云一句话英文识别、DeepSeek `deepseek-flash` 和腾讯云精品英文语音合成。小程序端只在开发版和体验版首页显示入口。

2026-11-17，单人试用的 `voiceChat` 云函数已配置 30 秒超时。用已授权的测试账号发送一句英文录音，约 4.7 秒收到识别文本、双语回复和英文音频。用户已确认手机能播放试听音频。

同日新增独立的计轮预览函数 `voiceChatQuotaTrial` 和账本 `voice_chat_quota_trial`，共用现有云开发环境。真实数据库已验证五轮耗尽、最后一轮并发、重复确认和第六轮拦截。开发者工具中一次真实语音请求经页面播放确认后从 5 轮变为 4 轮，重复确认保持 4 轮。

根据用户的测试要求，当前本人微信账号在两个试用函数中均已设置为不限轮。`quotaStatus` 实测返回 `kind: "unlimited"`。该账号的对话绕过额度预留与扣轮，可连续测试。家长体验的 5 轮规则保留给后续获邀体验账号。

修复首次录音时的说明弹窗按钮长度，将五个汉字改为四个汉字「同意继续」。原生预览和源码均已同步，回归测试校验微信弹窗按钮的四字限制。

## 错误分类与测试状态

2026-11-17 已将分类错误部署到两个单人测试函数，下载云端文件逐一校验 SHA-256 一致，并确认环境变量与 30 秒超时保持原值。新版原生预览与源码显示「内部测试 · 不限轮数」。已知为不限轮的账号遇到额度查询短暂失败时仍可继续测试。

| 环节 | 提示依据 |
| --- | --- |
| 录音 | 区分麦克风权限、隐私授权、设备占用、录音启停和文件读取失败 |
| 识别 | 只有识别成功但文字为空才返回 `NO_SPEECH`；识别服务异常、超时、繁忙和连接失败各用对应代码 |
| 回答 | 区分英文回答生成失败、等待超时及返回格式异常 |
| 发声 | 区分云端语音合成、手机保存音频和本地播放失败 |
| 账号与配置 | 区分试用权限、服务授权、服务商额度、配置及家长体验轮数；内部账号不执行计轮操作 |

服务端错误统一返回 `code`、`stage`、`retryable`，合法对话请求附 `requestId`。界面采用固定中文提示。诊断日志仅记录失败环节、安全错误码、白名单内的服务商错误码和请求编号，不写原始错误消息、录音、字幕或密钥。腾讯 SDK 未保留结构化故障信息时，保守显示对应环节暂时出错，不根据错误文字猜测用户是否讲清楚。

本次验证包括 24 类服务故障、不限轮账号连续 6 轮不访问额度账本、额度查询失败后的继续对话、客户端错误分类、录音及播放回归。真实云端验证中，无效音频被标记为识别服务错误，结构化日志可定位到 `FailedOperation.ErrorRecognize`；正常英文录音完成识别、双语回答和播放，约 8.1 秒，页面仍为不限轮。既往通用错误日志不足以还原每次失败原因。

## 云函数

1. 在微信开发者工具中确认小程序云环境，再部署 `cloudfunctions/voiceChat`，选择“云端安装依赖”。函数名必须为 `voiceChat`，入口为 `index.main`。不要把凭据写进仓库或小程序代码。
2. 在「云开发 → 云函数 → voiceChat → 函数配置 → 环境变量」中新增 `VOICE_CHAT_TENCENT_SECRET_ID`、`VOICE_CHAT_TENCENT_SECRET_KEY` 和 `DEEPSEEK_API_KEY`。可选的 `VOICE_CHAT_TENCENT_REGION` 默认 `ap-guangzhou`。保留其他已有变量。腾讯云语音密钥只需一句话识别和语音合成权限。云端使用上述名称，因为 CloudBase 保留了 `TENCENTCLOUD_` 前缀。[CloudBase 环境变量说明](https://docs.cloudbase.net/cloud-function/function-configuration/env)
3. 函数默认超时通常只有 3 秒，三段串行调用需要在函数配置里调高超时。先用 **30 秒**试跑，并核对真机调用是否能同步返回；如果实际服务耗时接近客户端等待上限，应缩短单段超时或改异步方案，不能仅把函数超时无限调大。
4. 先保持 `VOICE_CHAT_ENABLED` 不设置。在微信开发者工具的小程序控制台运行下面的命令，取得**当前微信用户自己的** OpenID；这条查询不调用付费服务。将获准试用的 OpenID 以英文逗号连接，配置到 `VOICE_CHAT_ALLOWED_OPENIDS`。未配置白名单时，即使开启总开关也不会调用语音或模型服务。

   ```js
   wx.cloud.callFunction({ name: "voiceChat", config: { env: "cloud1-6geu18jg425a604e" }, data: { action: "trialIdentity" } })
     .then(({ result }) => console.log(result.ok ? result.data.openId : result.code));
   ```

5. 设置 `VOICE_CHAT_ENABLED=true` 开启已授权账号的试用。开发版入口和云函数的服务端白名单分别控制页面展示和服务访问。

## 家长试用额度

建议每个获邀微信账号首次获得 5 轮免费对话。各难度、自由聊天和教材主题共用次数。拟试价 4.9 元，体验包到账起 7 天内共 50 轮。当前客户端没有收款入口。

启用计量前，在试用环境创建集合 `voice_chat_quota`，把客户端权限设为「所有用户不可读写」。部署匹配的云函数和小程序预览后，在函数的 `VOICE_CHAT_UNLIMITED_OPENIDS` 里填内部测试账号，同时保留这些账号在 `VOICE_CHAT_ALLOWED_OPENIDS` 中。把获邀家长加入允许名单，设置 `VOICE_CHAT_QUOTA_ENABLED=true`。未设置计量开关时仍按原来的单人试用方式运行。

每次新对话先暂留一轮，手机收到回复并首次开始播放英文音频后才确认扣轮。云端生成失败时释放预留。若手机断网，或用户在播放前退出，预留在请求开始后 120 秒到期。同一请求重复确认只扣一次。重听已有回复、本地跟读和回听自己的录音都不额外扣轮。账本仅保存额度、请求及确认所需的记录，不保存录音、字幕或回复内容。

体验包的服务端发放方法为 `grantPack(openId, orderId)`。它接收由商家后台核实的账号和订单号，同一订单只到账一次。支付和订单核验尚未接入。这套播放回执适用于受邀家庭试用。未收到播放回执的请求仍可能产生接口费用，公开销售时应另外设置按账号的调用上限。

## 真机验收

- 用开发版或体验版进入“英语语音伙伴”，同意说明并授予麦克风权限。说一句 2–5 秒的英语，验证转写、英文语音、英中字幕、回复时间和音频文件大小。
- 分别试自由聊天、四个主题与基础/进阶档；检查主题切换不带入上个主题、两档回复长度与语速不同、中文翻译对应英文、每轮至多一处纠正。
- 用“重听”“跟读”“回听自己”验证播放和本地录音；切换模式、后台切换、拒绝麦克风、断网时检查是否能恢复，旧请求不能写入新会话。
- 在云函数监控核对时长、错误、调用量和实际费用。代码不记录音频、转写或密钥到应用日志，但平台及服务商的数据留存须单独核验。

## 隐私与数据

聊天录音通过微信云函数发送给腾讯云识别；识别文本和最近最多 8 轮英语上下文发送给 DeepSeek；英文回复发送给腾讯云合成语音。应用当前不把聊天录音或聊天记录写入“我的打卡”或云数据库。页面卸载后清理应用生成的音频文件；微信临时录音由客户端尝试删除。腾讯云语音识别文档说明识别后的文本可能在其服务器保存 7 天；不能把“应用不保存”写成“服务商立即删除”。上线前应更新小程序隐私保护指引，核对实际服务条款和儿童使用场景。
