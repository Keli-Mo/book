# 跟读录音与分组目录交互设计

日期：2026-08-29  
适用分支：`codex/listening-checkin`

## 目标

在不恢复整本教材连续翻阅的前提下，优化单书跟读训练页：

1. 删除教材图片下方重复的“本页示范听力”信息框。
2. 录音期间允许用户手动播放教材页上的示范音频，形成边听边跟读的操作流程。
3. 为录音增加暂停、继续和结束控制。
4. 增加按章节分组的训练目录，快速跳转到任意含示范音频的训练页。

## 范围边界

- 最终录音仍由设备麦克风采集，不在客户端或云端数字合成示范音频。
- 不自动播放示范音频；用户在录音中手动点击教材上的播放标记。
- 外放示范音频可能被麦克风自然录入；需要减少串音时可使用耳机。
- 目录只包含 `SAMPLE_BOOK_PRACTICES` 中有示范音频的训练页，不提供无音频页面，也不恢复整本书连续翻阅。
- 不新增独立目录页面或首页目录入口，目录仅作为当前训练页内的快速跳转工具。
- 云端打卡的数据结构、上传流程和分享逻辑保持不变。

## 页面布局

### 训练页正文

- 保留课程名、章节名、训练进度、操作提示、教材图片、音频热点、录音区和上一个/下一个训练。
- 删除 `.practice-audio-status` 对应的整个信息框及样式。
- 在训练页头部进度区域增加“目录”按钮，显示当前训练序号与总训练数。

### 底部弹层目录

- 点击“目录”后显示遮罩和底部弹层，不离开当前页面。
- 弹层顶部显示“训练目录”和关闭按钮。
- 按现有 `sectionTitle` 分组；分组名称沿用教材数据中的“Unit N 课文/练习/绘本”。
- 每组列出该组全部训练页，单项显示“第 N 页”和音频段数。
- 当前训练页高亮，并在打开目录时滚动或定位到当前分组附近。
- 点击目录项后复用统一的训练切换流程，成功切换后关闭弹层并滚动到页面顶部。
- 点击遮罩或关闭按钮只关闭目录，不改变当前训练。

## 录音状态与控制

录音状态扩展为：

```text
idle → recording ⇄ paused → recorded → uploading
```

- `idle`：显示“开始跟读录音”。
- `recording`：显示“暂停录音”和“结束录音”。
- `paused`：显示“继续录音”和“结束录音”，状态文案明确为“录音已暂停”。
- `recorded`：保留回听、重新录制和完成打卡。
- `uploading`：禁止切页、重新录制和重复提交。

录音状态以 `RecorderManager` 的 `onStart`、`onPause`、`onResume` 和 `onStop` 事件为准，不在按钮点击后提前假定成功。

### 录音计时

- 录音中只累计实际录制时段。
- 暂停时冻结界面计时；继续后从已累计时长继续。
- 最终以 `onStop` 返回的录音文件时长为权威值，并沿用云函数的整数毫秒规范化。
- 最大录音时长仍为 5 分钟。

### 示范音频并行播放

- 移除 `playModelAudio` 在 `recording` 状态下的禁播条件。
- 开始录音时不再停止正在播放的示范音频。
- `recording` 和 `paused` 状态均可手动播放、停止或切换教材音频热点。
- 示范音频播放与录音暂停彼此独立：暂停录音不会自动暂停示范音频，示范音频结束也不会停止录音。
- 回听用户录音时仍先停止示范音频，避免两个回放音频同时播放。

## 切页与防误操作

- `uploading` 状态下禁止目录、上一页和下一页切换，并提示“打卡上传中，请稍候”。
- 当前存在 `recording`、`paused` 或尚未提交的 `recorded` 录音时，切换训练前弹窗确认“切换后将放弃当前录音”。
- 用户取消时保持当前训练及录音状态；用户确认后停止录音与音频、清空本地录音，再切换目标训练。
- 同一套确认逻辑同时用于目录跳转、上一个训练和下一个训练，避免行为不一致。

## 数据与组件边界

- 在听力训练数据层增加目录分组派生函数，只从 `SAMPLE_BOOK_PRACTICES` 生成展示数据，不复制教材页与音频映射。
- 目录组件只接收分组数据、当前索引、打开状态和选择/关闭回调，不直接操作录音管理器。
- 录音状态转换和有效录音时长计算保持为可独立测试的逻辑；页面负责连接微信录音与音频 API。
- 所有新增业务注释使用中文。

## 错误处理

- 录音暂停或继续失败时保持事件确认前的状态，并显示明确提示。
- 示范音频播放失败只结束当前示范音频状态，不中断录音。
- 目录数据为空时不显示目录入口；单个分组为空时不渲染该分组。
- 切页清理录音失败时仍以保护用户操作为优先，不上传残留临时录音。

## 测试与验收

### 自动化验证

- 目录按章节分组，顺序与 `SAMPLE_BOOK_PRACTICES` 一致。
- 每个目录项能映射到正确的训练索引、真实页号和音频段数。
- 录音状态支持开始、暂停、继续、结束的合法转换。
- 暂停期间界面计时不增长，继续后从累计值增长。
- 存在录音时切页必须经过确认；上传中切页被阻止。
- 原有云函数测试、错误提示测试、教材音频映射校验和微信小程序构建继续通过。

### 真机验收

1. 开始录音后手动播放、停止和切换至少两段示范音频，录音不中断。
2. 暂停录音，等待数秒再继续，最终录音不包含暂停空档且时长正确。
3. 录音中打开目录并选择其他页，确认取消与确认放弃两种路径均正确。
4. 通过目录跳转到不同 Unit 的训练页，教材图片、真实页号、热点和音频仍一一对应。
5. 完成打卡后能在“我的打卡”回听、分享和删除录音。
