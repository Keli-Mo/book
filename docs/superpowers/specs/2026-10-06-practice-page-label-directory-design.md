# 教材真实页码与目录细分设计

## 目标

跟读页顶部只显示当前教材的真实页标签，例如“第 7 页”；封面显示“封面”。训练目录继续保留逐页入口，并依据已核验的教材目录增加更细的章节、复习和附录分组。

## 已确认的问题

当前 `ListeningPractice.pageNumber` 同时承担资源身份和显示页码。它来自图片文件后缀，已经被练习 ID、音频映射、阅读进度、录音记录和回跳逻辑使用，不能为修正文案而改写。

部分资源文件号不等于教材印刷页码。例如剑桥 KET 综合教程学生用书（book ID `9`）的 `_8.png` 实际印刷页为第 7 页。顶部当前显示数组位置和总图片数，目录卡片当前显示资源文件号，所以用户会看到与教材目录不一致的数字。

## 数据设计

1. 保留 `pageNumber`、`imageIndex`、练习 ID、图片 URL 和音频键的现有含义。
2. 使用现有可选字段 `pageLabel` 保存用户可见的教材页标签。
3. 增加一个集中式页标签解析函数，输入 `bookId`、`imageIndex`、`pageNumber`，输出已核验的 `pageLabel`；没有可靠依据时不猜测，沿用当前页号。
4. `buildFullBookPracticeBundle` 对有音频页和无音频页统一应用页标签解析，避免同一页因是否有音频而显示不同页码。
5. 首页继续阅读、跟读页顶部、训练目录和录音详情继续消费同一个 `pageLabel`，底层历史定位仍使用稳定 ID、图片 URL 和 `pageNumber`。

## 顶部显示

顶部进度区域移除“跟读训练”和 `当前位置 / 总图片数`，只显示：

- 正文页：`第 N 页`
- 封面：`封面`
- 其他经教材明确命名的前置页：使用核验后的名称

播放进度条、目录按钮和 Header 布局不改样式。

## 目录细分

目录组件保持现有交互：章节折叠、逐页卡片、当前页标记和“定位当前页”都不变。细分通过 `catalogLists` 增加准确的起始节点完成，不增加新的目录层级。

本阶段完整处理 book ID `9`，依据用户提供的教材目录补充：

- `Map of the units`：教材第 4 页
- `Introduction`：教材第 6 页
- `A2 Key for Schools content and overview`：教材第 7 页
- `Vocabulary and grammar review 1–14`：教材第 20、21、34、35、48、49、62、63、76、77、90、91、104、105 页

现有 Unit 1–14 和 Grammar reference、Phrasal verb builder、Irregular verbs、Writing bank、Speaking bank、Extra resources、Answer key and audio scripts、Acknowledgements 的起始位置保持不变。

其他教材采用同一原则逐本核验：只有教材目录页或可靠原始 PDF 明确给出标题和起始页时才增加节点。本阶段不根据页数规律补造其他书的子章节。

## KET 页标签规则

book ID `9` 保留资源文件号作为 `pageNumber`。已核验的正文页使用零基图片索引对应教材印刷页码，例如：

- `_8.png`：`imageIndex = 7`，显示 `第 7 页`
- Unit 2 起始图片：显示 `第 14 页`

封面和前置页只在核验后给出专用标签；未核验页继续使用安全回退，不改变资源身份。

## 兼容性

- 不修改练习 ID、图片顺序、音频键、热点坐标和训练索引。
- 不迁移本地阅读进度或录音记录。
- `CheckInDetail` 仍按稳定 ID、图片 URL、资源页号和旧索引的既有顺序恢复。
- 目录分组 ID 只在当前会话使用，增加分组不会影响持久化数据。

## 测试

1. 先增加失败测试，证明顶部不再显示 `6 / 191`，而显示真实页标签。
2. 验证 book ID `9` 的 `_8.png` 显示“第 7 页”，同时 `pageNumber`、练习 ID 和图片 URL 不变。
3. 验证有音频页和无音频页使用同一页标签规则。
4. 验证 book ID `9` 的 17 个新增目录节点及每个节点的页范围与教材目录一致。
5. 验证目录细分前后仍为 189 张图片，逐页顺序、定位、音频数和历史回跳不变。
6. 运行目录、路由、阅读进度、录音恢复、音频映射、全量回归和微信构建。

## 发布边界

本阶段提交代码和测试，但不自动推送。其他教材的目录细分在取得可靠目录依据后，按相同规则继续补充。
